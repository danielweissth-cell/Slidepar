# Slidepar

Кроссплатформенный редактор презентаций (macOS, Windows 8+, Linux) на Electron.
Аналог PowerPoint: редактор слайдов, режим показа и экспорт в PDF.

## Запуск

```bash
npm install
npm start
```

> Если `npm start` выводит `Cannot read properties of undefined (reading 'whenReady')` —
> в окружении установлена переменная `ELECTRON_RUN_AS_NODE=1`. Запустите так:
> ```bash
> env -u ELECTRON_RUN_AS_NODE npm start
> ```

## Сборка установщиков

```bash
npm run dist:mac     # .dmg / .zip
npm run dist:win     # .exe (NSIS) / portable
npm run dist:linux   # AppImage / .deb
```

## Возможности (MVP)

- **Слайды**: добавление, дублирование (Cmd/Ctrl+D), удаление, превью в боковой панели.
- **Объекты**: текст, прямоугольник, эллипс, линия, изображения.
- **Редактирование**: перетаскивание, изменение размера за маркеры, двойной клик — правка текста.
- **Форматирование текста**: шрифт, размер, жирный/курсив/подчёркнутый, выравнивание, цвет.
- **Фигуры**: заливка, цвет и толщина контура, порядок слоёв.
- **Фон слайда**: палитра и произвольный цвет.
- **Режим показа**: F5 / «▶ Показ», навигация стрелками, Esc — выход.
- **Экспорт в PDF**: Cmd/Ctrl+E (каждый слайд — страница 16:9).
- **Сохранение проекта**: формат `.slidepar` (JSON), открытие/сохранение.
- **История**: отмена/повтор (Cmd/Ctrl+Z / Shift+Z).

## Структура

```
src/
  main.js            Electron: окно, меню, экспорт PDF, файловые диалоги
  preload.js         безопасный мост между окном и системой
  renderer/
    index.html       разметка интерфейса
    styles.css       оформление (палитра логотипа)
    app.js           вся логика редактора
assets/logo.png      логотип Slidepar
```
